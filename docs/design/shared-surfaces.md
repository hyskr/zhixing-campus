# 桌面与 Android 共用界面规范

## 颜色与表面

`src/theme-tokens.css` 是两端共用的颜色角色来源，最后加载以统一既有组件。经典使用绿色强调色和中性浅色画布，Claude 使用暖纸色画布和暖棕强调色。

| 角色 | 经典 | Claude |
| --- | --- | --- |
| 正文 | #242a27 | #302e2a |
| 辅助文字 | #626b65 | #6e665c |
| 主操作 | #294a3c | #604c3c |
| 卡片 | #ffffff | #fffefa |
| 页面画布 | #f5f6f4 | #f5f3ed |
| 边框 | #dfe4de | #dfd9ce |

状态采用独立的成功、警告、失败和信息颜色；课程色块保留类别差异。新增样式使用语义变量，避免同一组件在两端出现不同的灰色或选中颜色。

## 桌面与手机的分工

- 课程资料共用默认收起和显式批量选择；桌面用文件树／详情双栏，手机进入详情页面。
- 回放共用整行播放入口和主画面控制；桌面采用横向信息列和主辅视频布局，手机采用纵向单列。
- 表单允许按可用宽度换行；手机触控区保持较大，桌面使用紧凑按钮。
- 下载提示和通知共用 BeUI Animated Toast Stack。提示挂载到页面外层或当前全屏元素，保持可见和可操作。

## 反馈规则

普通成功提示自动消失；带操作入口的提示保留更久。下载准备显示加载状态，完成与失败通知保留到手动关闭。权限拒绝不影响下载及应用内结果提示。

下载记录提供速度、时间、保存位置、打开／导出和失败重试；进行中任务优先排列。系统完成通知按批次发送，减少多文件下载对通知中心的打扰。
