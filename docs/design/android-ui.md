# Android 界面设计

## 信息结构

底部固定：首页、课表、作业、邮箱、更多。每页只保留顶部一个标题；同步、搜索与校园动态在顶部操作区。内容遵循触屏阅读顺序，桌面双栏和表格按页面任务转为列表或详情。

| 页面 | 手机布局 |
| --- | --- |
| 首页 | 紧凑摘要、今日课程与邮件／作业／动态列表 |
| 课表 | 七天 × 七个时段，一屏周视图；点按格子在底部抽屉查看教师、地点、周次与课程空间入口 |
| 邮箱 | 收件箱／未读／已发送分段切换；搜索与写信；点邮件进入详情，返回保留列表位置；选择后显示批量操作 |
| 作业 | 状态分段、课程筛选、截止时间与提交状态优先；进入详情查看与提交 |
| 成绩 | 按学期分组，课程与教师放在一起，右侧对齐学分与得分；搜索与学期筛选后点按查看评分明细 |
| 课程资料 | 全宽文件树，勾选批量操作；文件和目录详情使用底部抽屉 |
| 文件与下载 | 单列文件行和任务卡片，速度不换行，任务进度与动作分层 |
| 教室 | 按日筛选，结果为教室列表及七时段状态条；点按查看整周 |
| 校园服务 | 余额摘要、分组网站入口和设备列表 |
| 设置 | 分类列表 → 分类详情，返回保留分类入口；账号与存储方式明确标注 |

## 设计语言

参考 [BeUI Native](https://beui.dev/react-native) 的触控设计，并继续使用本项目已安装的 BeUI React 源码。组件框架保留 Tauri WebView。

- [Card](https://beui.dev/react-native/card)：16 px 圆角、轻边界，列表分隔展示内容关系。
- [Tabs](https://beui.dev/react-native/tabs)：分段切换与滑动指示器，切换时保留页面上下文。
- [Button](https://beui.dev/react-native/button)：主要操作 48 px，图标操作 44–48 px，按压反馈短促。
- 使用现有 BottomSheet、Select、Input、Checkbox、AnimatedBadge 和 Toast；无障碍名称和键盘焦点保留，减少动态效果时不播放装饰过渡。

正文 14–15 px、标题 18–22 px、辅助文字 12–13 px。周课表为全周概览，格子文字 10–11 px；完整信息在抽屉中以正常字号展示。小屏并排冲突课程在同一格分行显示，超过两门显示数量并展开查看。

画布、卡片、边框与文字采用项目语义颜色，适配现有两种界面风格。课表保留课程色块作为定位线索，其余区域减少装饰色。

桌面成绩页保留原有独立列：课程名称、学年学期、任课教师、学分和成绩。移动端的合并信息行只用于手机布局。
