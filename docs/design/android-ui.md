# Android 界面设计

## 页面结构

知行的手机端以“今天要处理什么”为首页中心。底部固定：首页、课表、应用、作业、邮箱；应用居中，集中收纳学习工具、校园服务和个人设置。

| 页面 | 布局与操作 |
| --- | --- |
| 首页 | 日期与账号入口、今日课程卡片、两封重要邮件、一项最近待办、一条最新动态；各区可进入完整列表 |
| 课表 | 七天 × 七时段，完整周视图一屏展示；左右滑动切周，保留上一周／下一周／本周按钮；点课程进入详情页 |
| 应用 | 学习、校园与文件、我的三组入口；搜索可查课程、作业和业务页面 |
| 邮箱 | 收件箱、未读、已发送分段切换；列表进入详情，左滑标记已读／未读；浮动写信按钮进入编辑页 |
| 作业 | 状态和课程筛选，正文与提交在独立页面；返回编辑和放弃确认保留输入内容 |
| 成绩 | 学期分组、搜索与筛选；详情页显示成绩、教师、学分和评分构成 |
| 资料与回放 | 全宽文件树，勾选批量操作；目录、文件、回放和文档预览进入独立页面 |
| 文件与下载 | 文件行和任务卡片区分主操作与更多操作；复制、下载、删除记录在底部菜单中展示 |
| 教室 | 按星期、楼宇、周次筛选，点教室进入整周占用页 |
| 校园服务 | 余额、网站快捷入口和设备管理按业务分类 |
| 设置与账号 | 分类进入详情，账号信息与操作分组对齐，保留原页面返回位置 |

## 顶栏与系统栏

顶栏只有一个页面标题。首页显示“今天”、日期与教学周，右侧账号入口；课表保留同步按钮，应用、作业、成绩与资料提供搜索。可下拉刷新的页面使用当前业务刷新范围。

Android 原生窗口启用 edge-to-edge：系统状态栏和手势导航栏透明，时间、信号与系统导航仍由系统绘制。应用当前两种风格均为浅色，因此原生图标采用深色；网页背景延伸到系统栏下方。原生 `WindowInsets` 经 `CampusWindow.systemInsets()` 提供给页面，按 WebView 像素比例转换为 `--safe-*`，内容避开状态栏、导航区与屏幕缺口。输入法由原生调整可用高度，返回优先关闭输入法。

## 详情与返回

`MobileDetailPage` 承载长内容：固定顶栏、左侧返回、独立滚动正文；页面没有遮罩和外层浮动卡片。进入子页面时父页面保留且暂不可交互，返回恢复原位置。手机上的 `Modal` 内容默认使用此页面结构，桌面继续使用原有对话框或侧栏。

短决策使用确认对话框，文件动作使用 BeUI BottomSheet；打开文件预览后返回只退出当前预览，再次返回才离开上级文件或作业页面。已编辑正文离开前可以继续编辑。

## 视觉规范

- 正文 14–15 px，页面标题 22 px，首页标题 27 px，辅助文字 12 px。
- 可独立点击的顶栏控件使用 48 px 触控区；底部导航图标与文字共同组成点击区。
- 手机页面使用 16 px 内容边距，白色内容表面与浅灰背景分层；主要课程卡片使用深绿色，Claude 风格对应暖棕色。
- 列表采用少量分隔线与 16–18 px 圆角；同一控件的标题、辅助文字与动作对齐。
- 课表格子是全周概览，使用紧凑文字；完整课程信息在详情页以正文尺寸展示。
- PDF、DOCX 与 PPTX 默认适配可用宽度，保留缩放、翻页、目录与全文搜索功能。

手机页面样式集中在 `src/mobile.css` 和 `src/mobile-surfaces.css`。桌面成绩保留课程名称、学年学期、任课教师、学分、成绩独立列。

## 依据

- [BeUI Native](https://beui.dev/react-native)：触控 Card、Button、Tabs 与 Swipeable List 的设计语言；实现使用项目已有 BeUI React 源码。
- [Android edge-to-edge](https://developer.android.com/develop/ui/views/layout/edge-to-edge)：透明原生系统栏、图标明暗与安全区。
- [Android App Bars](https://developer.android.com/develop/ui/compose/components/app-bars)：标题、返回和页面操作的分工。
- [mobile-android-design](https://github.com/wshobson/agents/tree/main/plugins/ui-design/skills/mobile-android-design)：Material 3 信息结构、触控尺寸与安卓导航模式；本机已安装到 `~/.codex/skills/mobile-android-design`。

双课格子上下等高，每门使用自己的课程颜色并保留名称与地点；短屏名称显示一行，较高屏幕显示两行。三门及以上显示数量，详情页列出全部课程及教师、地点和周次。时段总数按星期和节次去重统计。
