# Android 0.15.0

[下载 APK](https://github.com/hyskr/zhixing-campus/releases/download/android-v0.15.0-preview.1/zhixing-campus_0.15.0_android-arm64.apk)

- 重做手机端顶栏：首页使用日期与账号入口，其他页面只显示标题和对应操作。
- 首页集中展示今日课程、重要邮件、最近待办和校园动态，统一字号、卡片和间距。
- 底部中央新增“应用”页，集中提供成绩、资料、教室、校园服务、文件、下载和设置入口。
- 原生状态栏与导航栏采用透明背景，系统图标明暗与应用浅色界面协调；安全区避开系统图标和摄像头。
- 文件预览、课程、作业、成绩、回放和搜索使用独立全屏页面，支持逐级返回；文件短操作保留底部菜单。
- 课表支持左右滑动切周，保持完整周视图一屏展示；同一时段的两门课程上下等高展示，各自保留颜色、课程名和地点；更多课程点开查看全部。
- PDF、DOCX、PPTX 初次打开适配手机宽度，优化预览工具栏、账号操作和分段选项对齐。

支持 Android 10+ arm64，可覆盖安装同签名版本。
