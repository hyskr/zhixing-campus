# 知行 Campus 0.16.0

## 应用内通知与下载

- 下载准备、排队、完成、失败和取消统一显示应用内浮动通知。完成与失败提示保留到手动关闭，可打开文件或查看下载。
- 下载通知优先显示在应用内，系统通知权限请求不阻塞下载；批量任务结束合并发送系统通知。
- 桌面工具栏和手机顶栏提供下载入口，进行中的任务排在下载记录前面。
- 新邮件、新成绩和上课提醒同步显示应用内通知，授权后也发送系统通知。
- 文件预览下载时显示忙碌状态；全屏中进入下载管理时自动退出全屏。

## 两端界面与操作

- 安卓近期的资料选择、回放与下载交互迁移到桌面，桌面按宽屏重新排布。
- 经典与 Claude 风格共用两端颜色角色：背景、卡片、强调色、正文、辅助文字、边框及成功／失败提示保持一致。
- 课程文件默认收起且无选中项，进入选择模式后才显示复选框和批量操作。桌面增加全部收起与详情区提示。
- 回放列表整行点击播放；桌面横向显示日期、时间与教室，手机使用紧凑列表。
- 播放器明确区分单画面和多画面同步，标出声音及进度所属主画面。桌面三视角布局放大主画面。
- 作业筛选、设置表单和长下拉选项支持按可用宽度换行。
- 安卓课表多课时段显示摘要与数量，进入详情查看全部课程。

## 发布

Windows、macOS Apple Silicon／Intel、Linux 由桌面 tag 构建并发布，包含应用内更新清单；Android 使用独立预览 tag 生成签名 APK。

本版本未运行额外功能测试。通知实际展示与播放效果以使用环境为准。
