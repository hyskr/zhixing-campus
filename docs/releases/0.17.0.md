# 知行 Campus 0.17.0

## 命令行与 AI 调用

- 桌面安装包内置独立 `zhixing` CLI，复用桌面保存的账号、凭据与登录会话，无需启动应用窗口。
- 设置 → 账号与凭据 → 命令行与 AI 调用，可安装终端命令；重新打开终端后生效。
- 提供账号、登录、课表、成绩、课程、作业、资料、回放、邮箱、教室、余额、设备与文件下载命令。
- `zhixing schema` 输出命令说明；管道默认输出 JSON，进度写入 stderr，退出码区分参数、登录、确认、网络和部分结果。
- `--refresh` 在会话失效时使用保存的密码登录一次；学校要求验证码时返回图片路径，人工填写后继续。
- 下载必须指定输出位置，修改邮件已读状态与退出登录需要显式确认。

## 页面刷新

- 启动先显示缓存；数据超过十五分钟或尚未同步时自动同步。
- 进入页面或回到前台时按模块缓存时间刷新；邮箱、作业与成绩各自检查。
- 编辑和详情查看期间暂缓刷新；失败保留缓存，五分钟后再尝试。

CLI 用法和各平台安装位置见 [命令行指南](../guides/cli.md)。
