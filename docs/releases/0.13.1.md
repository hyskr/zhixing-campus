## 更新内容

- 版本信息与发布说明通过原生请求读取公开更新清单，移除 GitHub REST API 查询，避免匿名接口 403 阻断版本检查。

- 优化正式安装包：启用体积优先编译、链接时优化、单代码生成单元及符号裁剪，移除权限中未启用的插件命令。
- 保留现有校园功能、离线验证码模型、DOCX／PPTX／PDF 预览和应用内更新。
- 新增系统托盘：显示主窗口、隐藏主窗口、退出应用。
- 关闭主窗口后默认驻留托盘，继续下载和提醒；可在“设置 → 外观”关闭。
- 再次启动应用时唤回已有窗口；macOS 支持通过 Dock 恢复窗口。

## 安装与更新

已有支持应用内更新的版本，可在“设置 → 应用更新”下载安装。Windows 使用 EXE 或 MSI，macOS 按芯片选择 DMG，Linux 使用 AppImage 或 DEB；DEB 通过安装包手动更新。
