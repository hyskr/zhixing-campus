## 更新内容

- 版本检查与安装包下载分别设置等待时间，支持较慢网络下下载更新。
- 设置新增“应用更新”：显示当前版本、最新正式版本和更新说明，支持下载、签名验证、安装及重启。
- Windows、macOS 和 Linux AppImage 支持应用内更新；DEB 安装版可从发布页面下载更新。
- 删除默认演示账户，保留已有真实账号与缓存。
- 修正 Windows 凭据保存方式下拉框宽度。
- 成绩和邮箱支持分别设置检查间隔。
- 智慧课程快捷入口先建立业务登录态，再打开课程首页。

## 安装

Windows 选择 x86_64 的 setup.exe 或 MSI；Mac 按 Apple Silicon / Intel 选择 aarch64 / x86_64 DMG；Linux 选择 DEB 或 AppImage。

旧版本需手动安装本版，后续可在“设置 → 应用更新”升级。macOS 安装包未公证，Windows 未配置发布者签名。
