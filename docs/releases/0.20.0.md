# 知行 Campus 0.20.0

- 作业要求与已交正文自动换行，图片随页面缩放，宽表格在正文内滚动，适配桌面与手机。
- 已安装的 `zhixing` 终端命令在桌面应用启动时自动刷新入口，随应用使用新版 CLI。
- Android 启动先显示缓存，首页按需更新邮箱、课表和作业，其他模块进入页面后刷新。
- 自动同步使用顶栏进度，不触发下拉动画；短暂切后台后延后刷新，失败保留缓存并提供重试入口。
- 邮箱和成绩沿用各自检查间隔，后台轮询复用近期同步结果，新成绩直接写回页面缓存。
- 应用与界面版本检查延后进行，成功后六小时内不自动重复检查，检查间隔跨重启保留。
- 修正 Android 搜索框重复边框和输入宽度。

Android 完整刷新策略需要安装本版 APK。桌面终端命令首次安装后，无需每次升级重新安装。
