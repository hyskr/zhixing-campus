# Android 0.14.1

- 课表改为一屏周视图：七天、七个时段同时展示，点击格子展开教师、地点与同时间课程。
- 邮箱采用列表进入详情，保留独立正文、收件箱／未读／已发送、选择后批量操作和返回列表。
- 手机成绩按学期分组，提供搜索与学期筛选、评分明细；桌面成绩表格保持原有独立列。教室改为座位与七时段占用列表。
- 设置改为分类列表进入详情；修正下拉选项单位显示，统一开关与表单对齐。
- 首页、作业、资料树、文件、下载、校园服务、账号和更多入口统一手机间距与触控布局。
- 参考 BeUI Native 的卡片、分段控件和触控反馈，沿用现有 Tauri Android 与校园接口。

支持 Android 10+ arm64，安装同签名 APK 可覆盖之前的 Android 预览版。后台提醒依赖应用进程运行。
