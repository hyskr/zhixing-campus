# CLI 提交与校园浏览窗口

CLI 支持 `homework submit`，正文来源可选直接参数、UTF-8 文件或标准输入，附件使用可重复的 `--file`。所有提交要求 `--confirm`；重复提交要求额外的 `--replace`，并提供完整正文与附件。学校禁止重复提交时直接返回错误。

CLI 与桌面界面调用同一份上传与提交实现。所有本机附件先确认可读，再依次上传；提交请求收到学校成功响应后返回 `submitted: true`。写操作不自动重放，错误后先读取作业状态。详细参数与示例见 [CLI 指南](../guides/cli.md)。

终端默认使用中文表格，管道默认 JSON；`--output table`、`--output text` 强制表格，`--output json` 保留完整结构化响应。部分读取失败仍显示成功结果和失败项。

桌面校园窗口通过 Tauri 新窗口请求处理创建关联 WebView，保留 opener、原生浏览上下文与 Cookie。主浏览窗口按校园账号区分，子窗口可继续打开下一层页面。

Android 校园窗口通过 WebChromeClient 接受子窗口请求，保留父页面并展示子页面；返回键先浏览当前页历史，再回到父页面。“关闭”退出校园窗口。第三方 Cookie 支持学校跨站登录流程，应用链接在系统中打开。

“最近更新”面板挂载到页面独立浮层并锚定通知按钮，避免页面筛选控件穿透；页面切换或打开对话框时收起。
